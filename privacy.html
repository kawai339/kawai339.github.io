プライバシーポリシー / Privacy Policy

制定日：2026年9月30日

1. 対象

本ポリシーは、KAWAI Publisher（以下「本ツール」）が YouTube API Services を通じて扱う情報について定めます。本ツールは運営者が所有するチャンネルの管理のみに使用し、第三者のユーザーには提供しません。

2. 取得する情報

  • Google OAuth による認可情報（アクセストークン・リフレッシュトークン）
  • 運営者の YouTube チャンネルID、アップロードした動画のID・タイトル・公開状態・予約日時
  • 運営者のチャンネルの視聴統計（再生回数、視聴維持率など YouTube Analytics API で提供される集計値）

3. 利用目的

自社チャンネルへの動画のアップロードと公開予約、アップロード結果の確認、および自社チャンネルの視聴成績の分析のためだけに利用します。広告配信やプロファイリングには利用しません。

4. 保存と管理

認可情報は運営者の管理するコンピュータ内の OS のキーチェーン等、アクセス制限された場所にのみ保存します。取得したデータは運営者のローカル環境にのみ保存します。

保存期間：YouTube API Services から取得した動画タイトル等の非統計データは、30日以内に再取得して更新するか削除します。再生回数などの統計データは、YouTube の派生指標とデータ保存に関する追加ポリシーで認められる範囲（最長36か月）で保存し、期間経過後に削除します。

5. 第三者提供

取得した情報を第三者に販売・提供・共有することはありません。

6. 削除とアクセスの取り消し

保存した認可情報とデータはいつでも削除できます。削除の依頼は下記お問い合わせ先で受け付け、7日以内に対応します。Google アカウントの アクセス権管理ページ から本ツールへのアクセスを取り消すこともできます。取り消し後、保存していた認可情報は削除します。

7. YouTube API Services

本ツールは YouTube API Services を利用しています。YouTube 利用規約 および Google プライバシーポリシー もご確認ください。

8. お問い合わせ

English summary

KAWAI Publisher uses YouTube API Services. It accesses YouTube API Services only to upload and schedule videos to, and read analytics for, YouTube channels owned by its operator. OAuth tokens and data are stored only on the operator's own access-restricted computer, are used only for those purposes, and are never sold or shared with third parties. Non-statistical API data (such as video titles) is refreshed or deleted within 30 days; statistics are kept no longer than 36 months as permitted by YouTube's additional policy on derived metrics and data storage. Deletion requests are handled within 7 days via the contact address above. Access can be revoked at any time at Google Account permissions. See also the YouTube Terms of Service and the Google Privacy Policy.
