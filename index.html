KAWAI Publisher

Developed with YouTube ／ YouTube API Services を利用しています

KAWAI Publisher は、運営者が自ら所有・管理する YouTube チャンネルへ、自作のオリジナル短尺動画（YouTube Shorts）をアップロード・予約公開し、その視聴統計を確認するための社内ツールです。第三者のユーザーやチャンネルには提供していません。

KAWAI Publisher is an internal tool used by its operator to upload and schedule original YouTube Shorts to YouTube channels the operator owns, and to review those channels' own analytics. It is not offered to third-party users.

利用する機能 / Features

  • YouTube Data API：自社チャンネルへの動画アップロード、公開予約、アップロード済み動画の状態確認
  • YouTube Analytics API：自社チャンネルの視聴統計の取得

本ツールは YouTube API Services を利用しています。利用者は YouTube 利用規約 に同意したものとみなされます。
